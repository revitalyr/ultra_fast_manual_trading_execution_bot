# Documentation

Interactive HTML documentation for the Ultra Fast Manual Trading Execution Bot.

## Contents

| File | Description |
|---|---|
| `index.html` | Interactive documentation with Mermaid diagrams (open in browser) |
| `mermaid-height-util.js` | Zoom/scale utility for diagram containers |

## Usage

Open `index.html` in any modern web browser. An internet connection is required for the first load to fetch the Mermaid library from CDN.

## Sections

- **📊 Overview** — System architecture and key capabilities
- **🏗️ Architecture** — Component interaction and concurrency model
- **🔄 Order Lifecycle** — End-to-end order flow and performance metrics
- **⚙️ Configuration** — Environment variables, match config format, examples
- **🛡️ Security** — Authentication, transport security, and secret management
- **🚀 Deployment** — Build steps, release optimizations, API endpoints

## Diagram Controls

Each diagram has floating zoom controls (+, -, reset). Use them to scale diagrams for better readability.
