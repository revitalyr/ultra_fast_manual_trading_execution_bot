Ultra Fast Manual Trading Execution Bot

Ultra-low latency manual trading execution bot for Polymarket. Built in Rust with lock-free data structures for sub-millisecond order dispatch.

📊 System Overview

The Ultra Fast Manual Trading Execution Bot is a Rust-based system engineered for professional high-frequency manual trading on Polymarket. It uses a three-layer architecture with lock-free data structures to achieve sub-millisecond execution latency.

Key Capabilities

  • Ultra-low latency execution with pre-built orders stored in lock-free structures
  • Parallel order dispatch for goal market and match result orders
  • Multi-match support with individual keyboard shortcuts per match
  • Minimal terminal UI designed for fastest possible execution
  • Zero-allocation execution path for maximum performance

🏗️ Component Architecture

The system follows an actor-based design with lock-free shared state. Each component runs in its own async task and communicates via channels. The architecture prioritizes zero-contention reads and minimal latency on the execution path.

Core Components

  • PolymarketClient — HTTP client wrapping all Polymarket API endpoints with connection pooling
  • ExecutionEngine — Bounded channel dispatch with parallel order submission via tokio::join!
  • MatchManager — Registry of active matches, coordinates lifecycle and keyboard dispatch
  • MatchEngine — Per-match state machine: orderbooks, prepared orders, market data handler
  • OrderPreBuilder — Builds goal and match orders from orderbook snapshots with price validation
  • KeyboardDashboard — Terminal UI with raw mode input, displays matches and execution feedback

⚙️ Configuration

The bot is configured via a TOML file and environment variables. Each match defines a goal market and a match result market on Polymarket, with an optional keyboard shortcut.
